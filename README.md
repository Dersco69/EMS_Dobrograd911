# Dobrograd EMS — GitHub Pages

Готовый статический сайт без сборки и зависимостей.

## Публикация на GitHub Pages
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи **содержимое** этой папки (файл `index.html`, `styles.css`, `script.js` и папку `assets`).
3. Открой **Settings → Pages**.
4. В разделе Build and deployment выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажми Save.
5. Подожди завершения публикации. GitHub покажет адрес сайта в разделе Pages.

Сайт не требует Node.js, сборки или сторонних библиотек. Доступность из конкретных сетей зависит от сетевых ограничений.
